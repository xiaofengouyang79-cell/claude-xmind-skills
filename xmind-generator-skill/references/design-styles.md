# 设计风格融合指南（Design DNA）

本技能把 5 个设计流派的「设计 DNA」融合进主题系统，让思维导图不再只有"绿/蓝/橙/紫"四种刻板配色。每个流派对应 1–3 套主题，主题名下方标注了设计来源。

## 设计流派 → 主题映射

| 设计流派（技能） | 核心设计 DNA | 对应主题 | 视觉特征 |
|------------------|-------------|----------|----------|
| **qiaomu-mondo-poster-design** | 丝网印刷、扁平色块、复古双色、留白叙事 | `mondo` | 奶油纸底 + 复古橙/棕/青高对比色块 |
| **frontend-design** | 选定方向并贯彻、白纸黑字 + 一个强强调色、直角/野兽派/霓虹 | `editorial` `brutalist` `neon` | 直角、纯原色、暗底霓虹 |
| **ian-xiaohei-illustrations** | 白底黑线稿、少量红橙蓝批注、大量留白、线框无填充 | `ink` | 线稿风（fill_mode=line） |
| **algorithmic-art** | 参数化、种子随机、色阶沿序涌现、受控混沌 | `spectrum` | 完整色谱沿分支顺序渐变 |
| **canvas-design** | 视觉优先、几何静默、Albers 色场、瑞士网格、负空间 | `gallery` | 克制的原色色块 + 直角 |

## 各流派设计 DNA 详解

### 1. Mondo 海报（qiaomu-mondo-poster-design）
- **丝网印刷感**：2–5 个扁平色块，无渐变、无阴影。
- **复古双色/三色**：橙/青、红/奶油、焦橙/芥末黄/棕（70 年代调色板）。
- **留白叙事**：负空间讲故事，单一焦点元素，symbol 优先于写实。
- **落地方案**：`mondo` 主题用奶油纸 `#FDF6EC` + 焦橙/芥末/青/品红/棕的扁平高对比分支色。

### 2. 前端设计（frontend-design）
- **选定方向并贯彻**：不要混搭风格，选一种走到底。
- **一个主色 + 选择性强调色**：优于平均分配的彩虹色（编辑感）。
- **反模式**：通用 SaaS 卡片堆、随机强调色、占位字体。
- **落地方案**：
  - `editorial`（编辑杂志）：白纸黑字 + 一个红色/琥珀强调色，直角边框，大量留白。
  - `brutalist`（野兽派）：纯原色、黑底、直角无圆角、高对比。
  - `neon`（复古未来）：暗底 + 霓虹粉/紫/青/黄。

### 3. 手绘小黑（ian-xiaohei-illustrations）
- **白底黑线稿**：黑色实心手绘线条，纯白背景。
- **少量批注色**：红/橙/蓝三点缀，其余留白。
- **怪诞但成立**：主体参与核心动作，不做装饰。
- **落地方案**：`ink` 主题启用 `fill_mode: "line"`——节点无填充、只用边框与文字（线稿感），主色为墨水黑，强调色仅红/橙/蓝。

### 4. 生成艺术（algorithmic-art）
- **参数化与种子随机**：同一系统、不同参数产生不同但可控的结果。
- **色阶沿序涌现**：颜色不是随机，而是沿结构顺序有规律地渐变。
- **受控混沌**：复杂但不杂乱，秩序在混沌中浮现。
- **落地方案**：`spectrum` 主题的分支强调色是一条完整色谱（玫瑰→橙→琥珀→绿→青→蓝→紫），分支越多，色谱越完整地"涌现"。

### 5. 画廊色场（canvas-design）
- **视觉优先、文字极简**：信息靠空间、色块、构成传达。
- **几何静默**：瑞士网格、克制秩序、戏剧性负空间。
- **Albers 色场**：原色色块相互作用的色彩关系。
- **落地方案**：`gallery` 主题用克制的原色色块（红/蓝/琥珀/青/灰）+ 直角 + 大量负空间。

## 扩展自定义主题

在 `assets/themes.json` 中新增主题，字段：

- `name` / `icon` / `description`：展示信息
- `family`：所属设计家族（用于分组）
- `root`：根主题色；`paper`：画布纸张色
- `accents`：7 个分支强调色（一级分支循环取色）
- `shape`（可选）：`org.xmind.topicShape.rect`（直角）等，默认圆角
- `fill_mode`（可选）：`"solid"`（实心，默认）或 `"line"`（线稿无填充）
