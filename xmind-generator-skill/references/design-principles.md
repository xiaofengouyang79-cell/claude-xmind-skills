# 思维导图设计原则

> 提炼自 XMind 官方设计方法论与 UI/UX 设计规范，是「好看即真理」的落地指南。生成任何思维导图前先读一遍，生成后再对照自查。

## 一、设计四原则（总纲）

一张好看的思维导图，本质是这四点的集合体。**大多数让人感觉杂乱的图，根本原因都是没做好「对齐」和「对比」。**

| 原则 | 含义 | 在思维导图中的落地 |
|------|------|-------------------|
| **亲近** Proximity | 相关的元素组织在一起 | 一个分支 = 一个语义组；别把无关内容塞进同一分支 |
| **对比** Contrast | 用颜色/形状/大小/粗细/明暗拉开差别 | 层级靠明暗深浅，分支靠色相，重点靠加粗+标记 |
| **重复** Repetition | 某些元素不断重复达到统一 | 同层级同字号同形状同边框；所有连线同曲线 |
| **对齐** Alignment | 让画面有秩序感 | 同级节点对齐，层级递进有序，别东一个西一个 |

## 二、配色三要义（最重要）

视频与 UI 规范高度一致的三条铁律：

1. **少用颜色** —— 一张图 3–4 个颜色就好，多了必乱。**唯一例外**是"彩虹分支配色"：一级分支用多色区分，但每个分支内部只用一个色系。
2. **降低饱和度** —— 低饱和度更柔和、更百搭，高饱和度容易"辣眼睛"。做法：主节点用 600 系列深色（保证白字可读），子/叶节点用 `tint()` 向白混合（越深越浅、越柔和）。
3. **智能对比** —— 文字颜色必须根据背景明度自动适配（深底白字、浅底深字），保证可读性。这正是脚本内置的 `readable_text()`。

### 配色均衡与明度对比

- 每个分支一个**色相**，分支内用该色相的**明度阶梯**（深 → 浅 → 近白）表达层级。
- 文字与背景对比度：标题（大字号粗体）≥ 3:1，正文 ≥ 4.5:1。
- 颜色不能是唯一的信息载体：层级差异同时用**字号 + 填充深浅 + 边框**表达，不能只靠颜色。

## 三、结构（Structure）

1. **选对结构**：平衡图发散思维、逻辑图表达总分关系、时间轴讲时间、组织结构/树形讲层级、鱼骨讲因果、矩阵讲多维对比。结构之间可混搭（每个分支可不同结构）。
2. **自由主题要对齐**：自由主题乱放最毁画面，落位后右键"对齐"。
3. **用外框线分组**：把某类内容框在一起，画面立刻整齐。
4. **同等级对齐**：当分支有填充和形状时，同等级对齐后画面瞬间变干净。

## 四、丰富度（Richness）

图"单调"的根因是丰富度不够，三条补救：

1. **手绘/贴纸/插画**：让图活起来。
2. **图标语义化**：图标要符合"快速理解"原则（钱币=金融、向上箭头=提升），好看之余还能快速定位重点。
3. **图片风格统一**：要么全卡通、要么全写实，别混搭。

## 五、生成前自查清单

- [ ] 根主题 5–15 字，简洁明确
- [ ] 一级分支 3–7 个，语义互斥、同级对称
- [ ] 每个分支内子节点完整覆盖该主题
- [ ] 层级 ≤ 4–5 层，叶子是可理解的最小单元
- [ ] 每层字号/字重/填充形成清晰阶梯
- [ ] 分支用不同色相，分支内用明度阶梯
- [ ] 图标/标记只用在关键节点（宁缺毋滥）
- [ ] 无多余的自由主题或悬空节点
