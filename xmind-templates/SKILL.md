## 使用方法

### 方式 1：场景驱动

用户描述用途，自动推荐模板：

```
用户: 我要做一个竞品分析
→ 推荐: Competitive Analysis 模板 (#9)
```

### 方式 2：直接指定

用户直接选择模板：

```
用户: 用 SWOT 模板
→ 使用: SWOT Analysis 模板 (#7)
```

### 方式 3：风格选择

用户选择视觉风格：

```
用户: 要一个科技感的思维导图
→ 推荐: 科技冷调配色 + 合适的模板
```

## 与 xmind-generator-skill 的协作

1. **选择模板** → 使用本 skill 的模板定义
2. **生成文件** → 调用 xmind-generator-skill 的生成逻辑
3. **应用样式** → 使用模板的配色方案和布局结构
